=========================================================
 GitHub Pages で公開する手順（はじめての方向け）
=========================================================

このゲームを、無料の「GitHub（ギットハブ）」に置くと、
インターネットで誰でも遊べる URL ができます。

公開のしかたは 2 通りあります。
  ★【かんたん】エディタの「GitHub に自動公開」ボタン（おすすめ）
  ○【手動】  ブラウザでファイルをアップロードする（自動が使えないとき）


=========================================================
 ★【かんたん】自動公開（おすすめ・git など不要）
=========================================================
エディタのボタン 1 つで、アップロードも「公開スイッチ」も自動でやります。
容量の大きいゲームでも、分割アップロードのような手間はありません。

■ 準備（最初の 1 回だけ）
---------------------------------------------------------
1. https://github.com/ で無料アカウントを作る（メールとパスワードだけ）。
2. ログイン後、右上の「＋」→「New repository」。
   - 「Repository name」に好きな名前（例: my-game）。
   - 「Public」を選ぶ（★GitHub Pages の無料公開は Public が必要です）。
   - 「Add a README file」等のチェックは入れない（空のまま作る）。
   - 「Create repository」を押す。
3. できたページの URL（例: https://github.com/あなたの名前/my-game）をコピー。

■ 公開する
---------------------------------------------------------
4. エディタで公開先を「GitHub Pages / itch.io 用」にする。
5. 「あなたの公開先リポジトリ URL」の欄に、3 でコピーした URL を貼り付ける。
6. 「GitHub に自動公開」ボタンを押す。
7. ★初回だけ：GitHub のログイン画面が開き、エディタに出た短いコードを
   入力して「Authorize（許可）」を押します。
   （この認証は最初の 1 回だけ。次回からは 4〜6 だけで公開できます。）
8. 自動でアップロード → GitHub Pages の有効化 → 完了すると公開 URL
   （https://あなたの名前.github.io/my-game/ の形）が表示されます。
   表示されるまで数分かかることがあります。これが遊べる URL です。

■ 更新したいとき
---------------------------------------------------------
・また「GitHub に自動公開」を押すだけ。同じ URL のまま中身が入れ替わります。


=========================================================
 ○【手動】ブラウザでアップロードする（自動が使えないとき）
=========================================================
自動公開が使えない場合は、ファイルを手で上げることもできます。

※ このフォルダの中身（index.html / Build / StreamingAssets / TemplateData）を上げます。
※ ★注意：ゲームが大きいと、1 回のアップロードでは「Commit failed（容量が大きすぎる）」
   になることがあります。その場合は、ファイルを数回に分けてアップしてください
   （例：先に index.html・Build・TemplateData、次に StreamingAssets の中のファイルを
   2〜3 個ずつ）。自動公開ならこの手間はありません。

1. リポジトリのページで「Add file」→「Upload files」。
2. 上げるファイルをドラッグ＆ドロップ →「Commit changes」。大きい場合は数回に分ける。
3. すべて上げ終わったら「Settings」→ 左メニュー「Pages」を開く。
4. 「Build and deployment」の下で、
    (1)「Source」が「Deploy from a branch」になっていることを確認、
    (2)「Branch」で「main」を選ぶ（アップロード後に出ます。無ければ F5 で再読込）、
    (3) フォルダは「/ (root)」のまま、
    (4)「Save」を押す。
5. 1〜2 分後に Pages 画面を再読込すると、公開 URL が表示されます。


=========================================================
 うまく映らない / 音が出ないとき
=========================================================
・開いた直後は読み込み中です。ローディングバーが終わるまで待つ。
・「クリックして開始」と出たら画面をクリック（最初のクリックまで音が鳴りません）。
・公開直後は URL が有効になるまで数分かかることがあります。
  404 が出ても、少し待ってから再読込すると表示されることがあります。
